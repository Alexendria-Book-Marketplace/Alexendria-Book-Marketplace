# BookNest — Pricing Page

Page de tarification pour un site de vente de livres usagés. Le code est fait avec HTML, CSS et JavaScript de base.

## Fichiers
- `pricing.html` : structure de la page.
- `style.css` : styles, mise en page et arrière-plan de bibliothèque.
- `script.js` : boutons, calcul des frais de 5 % et acceptation des conditions.

## Tester la page
Ouvrir `pricing.html` dans un navigateur. Une connexion Internet est nécessaire pour charger la photo de bibliothèque utilisée en arrière-plan.

## À vérifier avec l'équipe
- Les liens `index.html`, `features.html`, `home.html`, `team.html`, `return-policy.html` et `terms.html` sont des exemples de noms de pages. Remplace-les par les vrais noms de fichiers de votre projet.
- Le bouton Login et la recherche affichent actuellement un message de démonstration. Pour une vraie connexion ou une vraie recherche, il faudra les connecter aux fonctionnalités développées par l'équipe.
- La règle de calcul actuelle suit le schéma : frais de 5 % ajoutés au prix initial. Confirmez avec l'équipe si les frais sont payés par l'acheteur ou le vendeur.

## Ajouter ta partie au dépôt GitHub de l'équipe

### Méthode recommandée : travailler dans le dépôt commun
1. Ouvre le dépôt GitHub de votre équipe.
2. Clique sur **Code**, puis copie l'URL du dépôt.
3. Sur ton ordinateur, ouvre GitHub Desktop (ou un terminal) et clone le dépôt.
4. Place `pricing.html`, `style.css` et `script.js` dans le dossier du projet. Si le projet utilise déjà un dossier comme `pages/` ou `css/`, demande à l'équipe où ranger les fichiers et adapte les liens.
5. Ouvre `pricing.html` dans un navigateur pour tester la page.
6. Dans GitHub Desktop, vérifie les fichiers modifiés, écris un résumé comme `Add pricing page`, puis clique sur **Commit to your branch**.
7. Clique sur **Push origin** pour envoyer ta branche sur GitHub.
8. Sur GitHub, ouvre une **Pull Request** vers la branche principale (`main`) afin que tes collègues puissent vérifier et fusionner ta partie.

### Si votre équipe utilise déjà des branches
Crée une branche nommée `pricing-page` avant de modifier les fichiers. Évite de travailler directement sur `main`, surtout si tes collègues modifient le site en même temps.

### Important
Ne remplace pas le fichier `index.html` de tes collègues. Garde ta page dans `pricing.html`, puis relie-la à la navigation commune après avoir confirmé les noms de fichiers avec l'équipe.
